# Blender 独立模型重建

使用 `pnpm assets:build` 重建主场景和三个独立道具；使用 `bash scripts/build-assets.sh props` 只重建马匹、矿石和步兵。脚本从自身位置定位项目，支持 BLENDER_BIN，并能识别当前挂载的 Blender 应用。

glTF Transform 4.2.1 已锁入开发依赖及 lockfile。各道具导出后依次 dedup、Draco 压缩，然后删除精确命名的临时去重文件。避免原来的每条 dlx 命令都重复解析网络依赖。

实际执行 props 流程成功，Blender 源文件、GLB 和预览图重新生成。屋顶 3 项、砌体 2 项、步兵专用 1 项和独立道具 3 项检查通过。道具检查涵盖 GLB 头、文件长度、Draco 必需扩展、各图元压缩、法线、材质名、有限包围盒、地面高度和三角形/体积预算。

首轮网络解析较慢，改用本地依赖后主动停止旧构建并重跑成功；未重启训练或修改游戏存档。仅删除构建产生的 .dedup.glb 中间文件，可重新生成。本次改进是可重建性和资源检查，不声称模型视觉质量已经达到全面战争级别。
