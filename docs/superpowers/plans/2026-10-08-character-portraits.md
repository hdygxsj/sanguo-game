# 首批原创人物立绘接入

范围：曹操、荀彧、卞夫人三个独立原创人物图像。内置 image_gen，每人物单独提示词生成；不使用现有商业游戏图像，不声称历史人物真实容貌。原始 PNG、页面 JPEG 和完整提示词均保存于项目，见 `assets/portraits/README.md`。

UI 设计：遵循 game-ui-frontend 的地图优先原则，仅放在现有可收起的人物面板。104px 宽纵向立绘与属性并列，窄屏 84px，不裁掉头饰。未覆盖的人物明确显示待补，不复用不同人物图片；幼年人物不显示成人立绘；请求失败显示文字占位，切换人物后仍可正常加载其他图像。不会更改人物状态、官职、装备或回合。

实现验证：新增选择成人、女像、加载失败恢复、幼年人物保护测试，先看到缺少图像和占位导致失败，再实现组件。151 后端 + 61 前端测试通过。构建发现人物类型未从 web/types 导出，改为直接导入共享领域类型后构建通过；原有 1MB 战役大包警告仍存在。

实机验证：通过 CUA 的临时后台页打开既有 QA 战局，依次查看曹操、卞夫人、荀彧立绘并截图检查，均完整显示；切换曹安1 显示幼年人物，甘夫人显示立绘待补。390×844 视口 DOM 宽度/滚动宽度均为 390，人物属性区域宽 280，无横向溢出。窄屏截图在当前浏览器工具中缩小显示，未据此声称全部手机交互均已验证。恢复视口并关闭临时页，未推进回合（始终第 22 回合）、未修改用户战局。

未完成：其他人物立绘、完整三国人物阵容、寿终继承、美术进一步精修、经济与多势力实际胜局等仍属于活动目标，本批不代表总体完成。
