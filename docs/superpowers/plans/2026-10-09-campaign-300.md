# Compact campaign implementation plan

Goal: New campaigns contain 300 capturable sites, including independent farms, mines and horse pastures; preserve existing saves.

Architecture: Keep the full register generator for legacy maps and its tests. Add a deterministic selection layer to generation, retaining every commandery seat and important counties, distributing remaining slots across commanderies. Use the existing owner, garrison, adjacency, marching and capture pipeline for resource sites. Optional siteKind preserves old save compatibility. Resource revenue accrues only through owned-site fiscal settlement, not proximity to a city.

Tech stack: TypeScript domain, Fastify persistence, React/R3F map.

- [ ] Add generation tests: 300 dense IDs, all 105 seats, 13 provinces, resource types, symmetric connected graph, 16 faction starts; preserve explicit full-register tests.
- [ ] Implement selection in hanGeography with a separate mode parameter. Default generateBattle uses campaign mode, legacy snapshots never regenerate.
- [ ] Add explicit siteKind and horse resource trait, ownership-based resource income. Show resource ownership and capture benefit in selected-site panel, prevent scenic extra resources in new campaigns.
- [ ] Verify terrain-road connectivity on both map sizes, adjust tests tied to the previous default, test capture/revenue transfer and serialized legacy round trips.
- [ ] Run API/web suites and builds, restart only the local API, inspect new-game UI without changing existing campaign turns.

Existing user instruction authorizes design decisions without further questions. No commit, save migration or training restart is requested.

## Verification

Implemented 196 cities and 104 independent estates (35 farms, 35 mines, 34 horse pastures). Important counties are protected from estate conversion. New campaigns use the 300-site map; stored snapshots remain unchanged. Density normalization prevents the compact projection from collapsing roads and rivers after the reduction.

API: 222 tests passing. Web: 180 tests passing. Both production builds pass. Real UI creation produced 300 minimap targets; selecting a neutral mine displays garrison, independent ownership and +6 resource income, and opens the march form with that mine selected. No turn submitted during the browser check. Both full-register and new-map terrain-road connectivity tested.

Resources currently yield treasury income, not separate commodity inventories. Existing training process was not restarted; no new-policy fairness claim is made for the smaller map.
