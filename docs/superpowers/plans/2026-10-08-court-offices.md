# 中央官位：实现与验证

在现有人物、财政、自动战斗和回放架构中增加丞相、大将军、太府卿，不增加局内手动战斗。职位是游戏化设计，不主张完整还原汉末官制。

- 每个势力每个职位限一人，任免消耗正常回合。任命费分别为 80 / 60 / 40，额外每回合俸禄为 3 / 3 / 2。
- 成年、忠诚至少 50 的本方非君主人物才能任命；被俘、在途领军、兼任太守或已有中央职位者不能任命。
- 丞相与太府卿依据有效政治和忠诚提供定额收入，上限为 8 / 5；大将军提供至多 6% 全军自动战斗指挥加成。
- 文职不可领军，大将军可以。被俘或离开势力后加成立即无效，随后结算清理职位。卸任降低忠诚 10。
- 人物面板内使用折叠区域，回放中禁用操作；旧存档缺少 court 字段时视为空缺。

验证：领域测试覆盖任命费用、不可变输入、重复职位、薪酬与收益、年龄/归属/忠诚/资金/太守限制、大将军被俘后加成失效。界面测试覆盖真实任命动作和回放禁用。HTTP 测试验证任命持久化、重复拒绝不推进版本、免职，以及免职后历史回放仍保留原官位。API 196 项测试全部通过。

后续进展：AI 财政任官逻辑已补齐，详见同目录 ai-court 计划。当前正在运行的训练进程在本功能之前启动，不包含本次修改。不能据此宣称全势力胜率平衡已完成。
