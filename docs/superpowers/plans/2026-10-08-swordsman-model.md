# 剑盾兵微缩模型

Blender 步兵生成器新增 --sword：移除长矛、保留木盾，增加直刃、青铜护手、握柄与环首。生成 han-swordsman.blend、han-swordsman.glb 和预览，去重后 Draco 压缩约 35.2 KB。离线预览已检查，仍是静态低多边形微缩造型，不声称写实人物已完成。

新增 garrisonUnitSlots 按实际 sword / archer / 其他兵力分配唯一槽位，每城总数最多 8，未增加总展示人数；无兵力不显示，旧存档无 units 时兼容通用枪兵。剑盾兵与弓兵使用相同人体尺度，枪兵保留长矛高度。新增一个实例批次，共用淡出、阴影和 noRaycast。骑兵暂用通用造型，后续仍需真实骑乘模型。

混编测试先因零槽位失败，实现后验证 20 枪 / 40 剑 / 20 弓映射为 2 / 4 / 2 个模型。Blender 成功导出，资源结构/材质/体积检查通过；导出阶段单一木盾网格的 join 操作发出非致命警告，未影响输出。地图内剑盾兵实景仍需单独验收。
