# 弓兵驻军模型

使用原有原创 Blender 步兵生成器的 `--archer` 分支制作弓、弦、箭囊、五支箭与背带，移除长矛和盾牌；保留甲片、头盔、衣物和绑腿。保存 han-archer.blend、网页 GLB 与 qa-evidence/han-archer.png。已检查离线渲染，属于静态微缩低多边形造型，不是写实人物或动画兵种全集。

网页按城市真实 archer / troops 比例分配已有的避水驻军槽位，弓兵与持矛模型不重复占位，合计仍最多 8 人/城、56 城。独立实例批次与现有模型透明度、阴影、远景隐藏和 noRaycast 一致。其他兵种目前仍使用持矛造型，后续需继续补齐。

弓兵最大高度 1.73，长矛最大高度 2.58；为保持人体尺度一致，弓兵归一化目标为 2 × 1.73 / 2.58。原函数固定目标 2 的测试先失败，修改后通过。兵种比例测试覆盖混编、全弓兵、无弓兵、零兵力和槽位裁剪。

资源已去重并 Draco 压缩到约 36 KB，构建脚本包含新分支。离线预览已核对；地图内视觉验收仍待进行，不据离线渲染声称完成浏览器验收。

现有第 22 回合存档无弓兵，未修改或推进该战局。独立创建 `QA 弓兵混编验收`（cmuzhqemp0004isvpwgb2r7c6），第 0 回合濮阳设置枪兵 40、弓兵 40。通过实际郡县索引选城，放大至约 28.6 倍，截图可见城外陆地上两排共八名混编驻军，轮廓不同且未重复占位；反向缩小经过融合视图至约 1.1 倍政治版图，模型淡出、色块恢复 100%，选城和 80 兵混编详情保持不变。控制台错误列表为空。截图已在对话中检查，临时浏览器页已关闭，验收战局保留用于复现。

发现仍需修复：该城底座与河流重叠，整体城池与地表仍偏示意性。此验收只证明新模型集成及按钮缩放未明显回归，不证明滚轮所有临界区间或性能指标达标。
