# 可学习的后方调动特征

证据：前轮 diagnostic-198 第 118 回合，士燮有 18 个调兵候选，等待得分 8.9242，但多个后方调动只有偏置得分 8.3508。旧 f10 仅比较源城、目标城相邻敌城比例，后方至后方调动通常为零，无法表示投入规模或到达效率。

实现：策略版本 4，维度 21→23。保留所有旧维度；新增 f21=min(兵力/40,1)，f22=f21/实际剩余行军回合。使用同一寻路与行军计算，包含天气、兵种及统帅装备移动影响。未人为赋予正权重，旧版本升级补零且旧得分不变。它提供学习信号，不直接保证调动变优。

验证：两项新增测试及两项迁移断言先失败再通过；pnpm test 共 230 项（API 156、Web 74），pnpm build 成功。旧模型版本 1/2/3 仍按原维度加载，版本 4 按 23 维加载。战役 chunk 警告仍存在。

训练：seed 199 的 32 集自博弈已完成，归档 data/training-history/run-1791439609970-199-574.json。新增两维学得权重 0.1706573、0.0898502，但候选平均领土 60.125，现有 64.0625；16 席位 120 回合评估双方均无胜利、全部未决。候选被拒绝晋升（territorial-regression），在线仍使用版本 3 / 542 集检查点，新特征代码已部署但不会伪装成已晋升的行为改善。总体获胜平衡要求尚未完成。
