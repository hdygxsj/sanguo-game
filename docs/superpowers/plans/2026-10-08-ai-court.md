# AI 任官实现计划

目标：让规则与学习型 AI 都能合法、可持续地使用中央官位，不提供免费任命或隐藏加成。

架构：独立 courtInitiative，沿用 validateCourt、courtBudget、fiscalEstimate 与贸易收入。每 11 回合错峰检查一次；文官只接受正净增收且 45 回合内回本的任命，大将军只在战争中且统率至少 70 时考虑。任命后保留 100 加 20 回合预计赤字的现金。按收益选择，不自动罢免或抢占太守。

步骤：先写候选与预算测试并观察失败；实现纯决策函数；接入 strategies 与 learning；跑 API 全量测试与类型检查。当前运行中的训练不重启，它使用此前载入的代码，不能作为本次行为的评估证据。

验证结果：先观察任官返回 undefined 的预期失败，再实现规则。4 项新测试覆盖合法且不修改输入、现金储备、玩家排除、太守排除、和平低收益拒绝、两种策略共用。全量 API 200 项通过，API 类型检查与构建通过。一次测试夹具误用不存在的 relations 字段，已改为真实 diplomacy 和 peace 状态。

尚未证明任官改善全图胜率；这是规则补齐，不是新的训练成果。后续必须重新进行双方同环境对照评估。
