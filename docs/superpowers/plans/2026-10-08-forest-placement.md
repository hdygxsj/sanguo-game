# 平原与山林分布

旧实现只生成约 22 候选点/平方地图单位，且排除高度低于 .085 的地块和所有城池 .095 半径，导致平原大片无树。

现改为固定种子的抖动网格和连续疏密变化；低海拔平原也允许生长，陡坡和高峰仍排除。圆形空地与线形通道使用空间网格索引避让，覆盖实际城池尺寸、农田、驻軍槽位、矿场马场、河流和道路。地图坐标、资源数值、寻路不变。近景树冠/树干仍采用实例化，两批、最多 650 棵，按镜头距离优先选择，远景依照原模型透明度隐藏。

验证：新增分布测试先失败后通过，覆盖低平原、确定性、圆形/河道空地及地图外排除。159 项前端测试通过。构建发现资源类型可为空的 TypeScript 错误，已改显式 horse/mine 判断并成功构建。独立 QA 战局临时页 42 在濮阳约 28.7 倍视角看到成片树林，农田/河道/驻军未被覆盖，控制台 error 为空；缩小至约 1.3 倍显示 100% 政治色块。未修改玩家战局，临时页已关闭。

仍需改进：当前树冠模型偏圆且偏大，后续应替换/调整为更自然的中式山林轮廓。没有测量 FPS，不能据此宣称性能全面达标。650 上限处的逐树淡入淡出尚未独立验证。
